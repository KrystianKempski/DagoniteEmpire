# Eastern March map

Place your high-resolution map image here as:

**`eastern-march.jpg`**

Current file is about **8192 × 6690** px. The map viewer preserves that aspect ratio (contain-fit); it does not stretch.

The barony **March map** tab loads `/maps/eastern-march.jpg` by default. Game Masters can change the image URL in map edit mode.

After adding the JPEG, open **March map** → **Edit map** and drag markers to the correct positions. Use **Connect** to draw **road** or **river** trade links between nodes.
